# Classfolio roadmap

1. **Product workspace — completed.** A branded overview, editable score sheet, student rankings, CSV export, and printable report previews. A single fixtures module supplies demonstration data for three senior classes, three terms, and twelve subjects. Score changes recalculate the connected previews and reset on refresh.
2. **School records and computation.** Set up Netlify Database with Drizzle, school sessions, classes, students, subjects, and term assessments. Add validated score saving and a workbook import preview with explicit column mapping. Confirm test/exam limits with the school: the current preview uses 40/60, but the workbook does not clearly declare limits. Confirm inconsistent remark thresholds between subjects, blank-score handling, ties, rounding, and ranking eligibility against worked examples. Retain the workbook’s A/B+/B/C/D/E/F grading boundaries unless changed by the school.
3. **Staff access and administration.** Add Netlify Identity, school setup, administrator and teacher roles, subject assignments, and permissions enforced on the server. Include school branding and configurable grading policies.
4. **Results review and publishing.** Add completion tracking, result approval, locked published terms, comments, attendance, and printable school-branded reports. Keep drafts separate from published reports and audit score changes.
5. **Annual results and family access.** Implement the ranking-sheet workflow, agreed annual aggregation and promotion rules, historical comparisons, secure parent access, and batch report downloads. Validate all calculations against the original workbook and school-approved edge cases before production use.
